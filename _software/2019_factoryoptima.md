Web prototype where manufacturing engineers build, optimize and compare factory designs. It draws on a reusable library of performance models and shows the trade-offs between options.

Factory Optima ([PAPER](http://www.ncbi.nlm.nih.gov/pmc/articles/PMC6605078/pdf/nihms-1526076.pdf)) is a web-based prototype system that allows manufacturing process engineers to compose, optimize and perform trade-off analysis of manufacturing service networks based on a reusable repository of performance models.
